# Junsheng Liu Academic Pages Website Content

This package converts Junsheng Liu's CV into the structure used by the Academic Pages GitHub Pages template.

## Recommended setup

1. Go to the Academic Pages repository:
   https://github.com/academicpages/academicpages.github.io
2. Click **Use this template**.
3. Name the new repository:
   `your-github-username.github.io`
4. Download and unzip this package.
5. Copy these folders/files into the new repository, replacing template files where needed:
   - `_config.yml`
   - `_data/navigation.yml`
   - `_pages/`
   - `_publications/`
   - `_teaching/`
6. Edit `_config.yml`:
   - Replace `your-github-username` with your real GitHub username.
   - Replace `repository` with your real repository path.
7. Commit and push changes.
8. GitHub Pages should build the site automatically.

## Important

The Academic Pages template expects many theme files from the original template repository. This package contains your personalized content and configuration, not a full copy of the entire theme repository.
