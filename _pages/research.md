## Independent Study on Set-Sequential Labelings

**Prof. Ervin Győri, Alfréd Rényi Institute of Mathematics**  
*May 2020–June 2021*

- Found examples of trees with 8, 16, or more vertices that are set sequential.
- Discovered necessary conditions for an odd-degree tree to be set sequential.
- Proved certain odd trees with selected properties are set sequential using different construction methods.
- Provided insights toward the conjecture that all odd trees are set sequential by a pairing conjecture.
